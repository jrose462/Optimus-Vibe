# Privacy

Optimus-Vibe has no accounts, telemetry or analytics. It talks to GitHub only for: update checks (anonymous, via GitHub
Releases), syncing **your own** config repo if you choose the GitHub provider, and bug reports you choose to send.

## Bug reports are PUBLIC

**Report a problem** files a public issue on `jrose462/Optimus-Vibe`. It is authored by your GitHub account if you are signed
in, otherwise anonymously through the app's built-in issues-only token. Anyone on the internet can read it. The app shows the
exact text in a preview, and Send stays disabled until you have previewed the current text.

### What a report contains

- Your description
- App version, which exe it came from, Windows version and architecture
- Device profile name and how it was chosen, manufacturer and model, CPU name, GPU names
- Sync provider (git or github) and the config repo name (never tokens)
- Game id and preset, if you reported from a game
- The last ~200 lines of the app log

### What is removed automatically

GitHub tokens; `Authorization` and Bearer values; email addresses; your Windows user name wherever it appears, and
`C:\Users\<name>` paths (shown as `%USERPROFILE%`); your machine name; IPv4 and IPv6 addresses; Steam64 ids and Steam account
folder ids in `userdata` paths. Redaction is pattern based and best effort: **read the preview** and edit your description if
anything personal remains. Never paste secrets into the description.

### Removing a report

Delete the issue if it was filed under your account, or ask the maintainer to delete it.

## Your settings

Presets, manual saves and settings live in your own config folder or private repo, never in this repo. The app reads game
config files and Steam's `localconfig.vdf` locally to do its job. Nothing is uploaded except by the sync provider you configure.

## Claude

Public bug reports are read by Claude (Anthropic) in GitHub Actions to triage them and propose fixes, so do not include
anything you would not want processed there. Game presets are generated by Claude in your own session and stored in your
private config repo.
